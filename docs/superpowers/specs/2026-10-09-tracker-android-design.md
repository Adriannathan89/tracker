# Tracker Android

Build a complete Flutter/Dart Android client in `mobile/`, alongside the existing Angular client in `app/`. Reuse the current Rust API and database, without adding a model service or changing browser authentication. The default API is `https://tracker.adrianportofolio.my.id/api/` and is configurable at build time. Android application ID: `my.id.adrianportofolio.tracker`; display name: Tracker.

Match the existing mobile web design: warm cream canvas, white rounded cards, near-black balance hero, lime highlights, semantic red/green money, Indonesian copy and Rupiah formatting. Support light/dark themes, safe areas, keyboard scrolling, empty/loading/error states, pull to refresh and accessible labelled controls. Navigation: Beranda, Catatan, central add action, Teman, Saya.

Feature parity: login/register/logout and persistent sessions; balance/cash/debt/receivable overview and recent committed records; search and period/type/draft filters; two-stage amount/details entry with backend classification; draft confirmation with primary/secondary category correction and draft deletion; friends/search/request sending/accept/reject; per-friend debt balances, debt creation and debtor-only repayment; profile rename; Discord verification code, external bot installation, verification status, disconnect, commit/weekly notification settings. The app needs a network connection; no offline mutation queue or fabricated financial data.

Use focused presentation screens, a ChangeNotifier controller for coherent shared data, typed API models, an injectable HTTP transport and a session store. Persist only cookies and appearance in Android secure storage; never passwords. Respect cookie expiration/Secure, share concurrent refresh, retry once after refresh, and preserve credentials on network errors. Do not follow API redirects or send cookies to another origin. Financial writes are never retried on network errors. Native HTTP requests omit browser-only Origin/Sec-Fetch headers, which the current API supports.

Android configuration follows Flutter 3.35.7 defaults: AGP 8.9.1, Kotlin 2.1.0, Gradle 8.12, JDK 17, compile/target SDK 36, min SDK 24. Release requires HTTPS; debug permits local HTTP. Include development signing for installable local APKs and optional private release keystore configuration. Ignore keystores, generated build/SDK paths, and environment files. Supply a manual GitHub Actions build that analyzes/tests and uploads APK artifacts without deployment.

Verify session expiration/refresh/network failure, numeric and category contracts, data filtering, UI login/navigation/form flows and narrow layouts. The current workspace has no Flutter/Dart/Android SDK and terminal network resolution is unavailable: record this limitation explicitly; do not claim compiled APK or passing Flutter checks without execution.
